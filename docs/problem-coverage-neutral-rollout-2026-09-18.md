## Границы и откат

Миграции схемы/данных, запуск migration job, перепубликация страниц, IAM, secrets, DNS и
конфигурация pipelines не изменялись. Штатные backend pipelines обновляют конфигурацию/image
migration job, но в этой задаче job не запускалась.

Предпочтительный откат: сначала CMS-front, затем backend, через проверенный revert и штатные
pipelines. Аварийный возврат трафика на предыдущие ревизии из таблицы требует отдельного
согласования. Откат БД не нужен. Backend-only откат совместим по API, но может вернуть красные
индикаторы допустимого отсутствия страницы.

Ручная приёмка после обновления CMS: открыть список проблем услуги; проблема без собственного
slug должна показывать «Без окремої сторінки», её региональные отсутствия не красные, создание
недоступно. При корректном slug и отсутствии страницы индикатор остаётся нейтральным, создание
доступно. Проверить также случай отсутствующего slug родителя: блокировка остаётся видимой.
