# Индикаторы runtime-секции «Практики в футере»

Согласовано 2026-09-18 после обнаружения ложной ошибки «не опубликовано» в CMS.

`site_footer_practices` формируется автоматически из видимых практик и не требует собственной
публикации. Отсутствие версии не является ошибкой и не увеличивает число неопубликованных
глобальных секций. Публиковать фиктивную версию для снятия индикатора нельзя.

Backend явно различает режимы `publicationMode: runtime | versioned`. Для runtime статус
определяют реальные ошибки и предупреждения источника, а не наличие версии. При исправных
данных статус `ok`, подпись «Формується автоматично». Старые версии не вызывают ожидание
публикации; действия редактирования и публикации остаются запрещёнными.

Навигация не возвращает runtime-секции блоки публикации, версий и влияния публикации. Общие
счётчики учитывают только секции с версионной публикацией. Настоящие предупреждения о названии
или маршруте практики сохраняются. Обычные глобальные секции сохраняют прежние правила.

Для расчёта используется узкое чтение практик и перевода выбранной локали одним запросом,
без загрузки дочерних карточек и без создания строк переводов. Сохраняются правила отображения,
сортировки и существующий fallback для отсутствующей строки украинского перевода.

Область изменения: CMS backend, без правок CMS-front/публичного frontend, миграций и изменений
живых данных. В API добавлен режим секции; существующий CMS-front принимает отсутствие
публикационных полей. Отдельный новый UI-бейдж не реализуется этой backend-правкой.

Технические детали: `cms-back/docs/runtime-global-section-indicators.md`.

Локальная проверка: 991/991 тестов backend, production TypeScript build и проверка diff успешны.
Рабочая ветка backend: `codex/footer-runtime-indicators`. Commit/push/deploy этим шагом не выполнялись.

Приёмка после отдельного выката: проверить отсутствие ложной красной ошибки и лишнего `0/1`
у практик футера, сохранение реальных предупреждений и прежнее поведение обычных
неопубликованных глобальных секций.
